# Android 与 macOS 功能对照

对照依据为 `DanmakuPlayer-macOS-Feature-Inventory(1).md` 中的 macOS 0.1.0 构建 9。Android 对应 0.4.0 预览版。0.3.0 真机记录列在文末，本版验证状态见 [Android README](README.md)。

## 媒体库与资料

| macOS 清单项目 | Android 对应功能 | 差异或待验收 |
| --- | --- | --- |
| 分类、剧集分组、搜索、排序 | 全部、电影、剧集、继续观看、文件不可用。按标题或最近播放排序，可和搜索组合。剧集按标题分组，标题排序时按季和集排序。 | 使用 Android 卡片列表，详情支持切换为双栏。 |
| 海报、进度、已看完、弹幕关联、详情 | 卡片显示海报、观看进度、观看和关联状态。可用「更多」或长按打开详情，支持继续播放和进入弹幕设置。 | 双栏和 TalkBack 全流程待验收。 |
| 文件和文件夹导入 | 系统选择器多选视频、递归扫描文件夹、跳过隐藏文件。支持系统打开视频请求。 | 多窗口拖放待适配。 |
| 重扫、去重与合并 | 记住导入位置，可重扫或取消重扫指定位置。匹配到已有文档时保留 ID、手动资料、播放进度、来源和校准。 | 去重以系统文档标识为主。不同提供者暴露同一个文件时，若无法识别为同一文档，可能有重复记录。 |
| 文件名、容器、NFO | 识别年份与季集。系统可读取时导入片长和容器标题。按同名 NFO、`movie.nfo`、`tvshow.nfo` 查找。 | 同目录资料需要文件夹访问权限。单选视频时可读该视频的容器资料；同目录 NFO 和海报可通过导入所在文件夹补齐。 |
| 海报、缩略图、手动编辑 | 按同名 JPG/PNG、`poster.jpg/png`、`folder.jpg` 查找。在支持的 Android 系统上尝试生成缩略图。可更换本地图片和编辑片名、年份、季集、简介、已看完状态。 | 平台取帧失败时显示占位。libmpv 截帧后备及 HEIC 跨设备验收待补。 |
| 文件不可用、重新定位、移除 | 文件不可用时保留库记录，可筛选或重新定位。移除记录保留原视频。 | Finder 定位属于 macOS 入口。外置存储断开重连待验收。 |

## 播放、音轨和字幕

| macOS 清单项目 | Android 对应功能 | 差异或待验收 |
| --- | --- | --- |
| libmpv、播放控制、全屏和倍速 | libmpv 硬解、播放暂停、时间轴、双击快退快进 5 秒、0.5× 至 2× 和全屏。 | 采用 Android 播放页面和系统全屏。 |
| 音量、音轨、字幕 | 应用内 0–100% 音量、选择音轨和字幕轨、外挂 SRT/ASS/VTT/SSA、微调字幕延迟。授权文件夹时检测同名外挂字幕。 | VTT、SSA 和字幕延迟的目视验收待补。 |
| 播放列表与切片 | 播放列表来自打开时的媒体库分类、搜索和排序，切换前保存当前进度。 | 桌面播放窗口聚焦由 Android 页面导航替代。 |
| 续播、已看完、错误 | 约每 5 秒和离开时保存，观看超过 95% 自动标记。可手动修改已看完状态。错误显示在播放器内，可关闭提示。 | 应用被系统强制结束时，以最后保存的进度为准。 |
| 电源与快捷键 | 前台播放时保持屏幕亮起，暂停、片尾或离开时释放。物理键盘可用空格、方向键、F 和 D。 | 系统休眠唤醒、键盘全流程和辅助技术待验收。macOS 的导入快捷键通过 Android 按钮执行。 |

## 弹幕、校准与数据

| macOS 清单项目 | Android 对应功能 | 差异或待验收 |
| --- | --- | --- |
| B 站搜索、链接、分 P 和确认 | 支持普通和官方影视搜索、BV、普通长链接、短链接及公开番剧单集链接。选择分 P 或单集后，先验证缓存或下载再保存，新来源失败时保留原关联。 | Pixel 上的片名搜索曾触发 B 站网页验证。公开番剧链接已实测，短链接与分 P 的完整真机回归待补。 |
| XML 和缓存 | 新导入的 XML 验证后保存应用内副本，可清除副本。网络弹幕按 BV/CID 缓存并兼容上一版本缓存。完整下载后替换，刷新出错时可回读旧缓存。 | 独立真实断网和 64 MB 边界素材待验收。 |
| 与播放时间同步的弹幕显示 | 支持滚动、顶部、底部、避碰与黑色描边。字号、透明度、区域、滚速、同屏上限和屏蔽词可调，可恢复默认。 | 手机的字号范围按 Android 显示规格设置。密集弹幕长时前景运行和屏幕级同步误差待测。 |
| 单片时间校准 | 整体秒数、±0.5 秒微调、添加和删除分段点，与媒体记录一起保存。 | 《火线》本地 62:06、B 站 55:30。整体延后已在前一版实测，两版内容的逐段校准仍待做。 |
| 数据、诊断、发行 | 使用 Android 应用私有存储，支持在系统文件选择器里导出诊断日志和查看本地版本。APK 可覆盖安装，沿用原测试签名。 | SQLite 文件级备份回退、跨设备资料迁移以及正式发行签名待补。macOS 的数据目录入口、DMG 和公证属于该平台。 |

## 0.3.0 真机记录

- Pixel 4 XL（Android 13、arm64）覆盖安装后，《火线》保持原播放进度和来源，从约 4:01 续播，继续使用硬件解码并读到 1,057 条旧缓存弹幕。
- 同一手机的测试文件夹包含短 MKV、NFO、PNG 海报、同名 ASS 与 XML。验证情况与限制以该版本的实测为准。
- 目前的真机播放记录以 1080p HEVC/MP4、H.264/MKV、AAC、外挂及内嵌 ASS 为主。macOS 清单中的 MOV、WebM、AVI、4K 组合、损坏样片和其他 Android API 级别仍需单独回归。
