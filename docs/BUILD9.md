# 构建 9：通过 B 站链接导入弹幕

2026-11-22 新增清晰的链接导入入口：播放窗口“弹幕设置 → B 站链接”、影片详情“通过 B 站链接导入弹幕”，以及媒体库菜单。同一个来源窗口可切换片名搜索和视频链接。

使用：粘贴视频链接／番剧 ep 链接／BV 号 → 解析链接 → 核对标题、UP 主、时长及分 P → 确认导入。链接带 p= 时自动选中对应分 P；不带分 P 默认 P1，仍须确认。不会下载或替换本地视频。

b23.tv 链接通过 HEAD 解析，逐次重定向仅允许 HTTPS B 站域名。短链接失败会提示复制完整链接。无效链接、分 P 不存在、受限或请求失败均显示真实错误；原影片来源不会因为解析或下载失败而清空。修改输入后清除旧候选，防止误确认旧链接。确认导入先取得真实／已缓存弹幕，再保存来源；保存失败留在窗口并显示错误。重复同一 BV/CID 保留校准；切换 CID 重置校准；现有 XML 在成功确认后切换为网络来源。
