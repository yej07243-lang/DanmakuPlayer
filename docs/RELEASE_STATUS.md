# 原版构建 9 的安装包整理

只整理原版发行材料和签名，不增加播放功能、不替换用户安装版、不重编播放器。应用及 44 个依赖的可执行代码段在签名前后、Xcode 上传前后均逐一核对一致。

## 发布方式

项目所有者决定跳过 Apple 公证，以 Developer ID 签名版提供直接下载。该选择只改变系统信任提示，不改变应用代码。首次从网络下载并启动时，macOS 可能显示“Apple 无法验证”，用户需要在“系统设置 → 隐私与安全性”选择“仍要打开”。下载页必须持续明确标注“未公证”。

安装包使用 Developer ID Application 签名和安全时间戳；45 个二进制均通过签名验证。DMG 本身也已签名并通过磁盘映像校验。`spctl` 返回 `Unnotarized Developer ID`，这是当前发布方式的预期结果。

## 最新核验

2026-11-22 14:37 UTC（北京时间 22:37），Xcode Organizer 及命令行导出均显示公证处理中。2026-11-23 项目所有者明确选择跳过公证；因此不再等待 Apple 处理，也不会把该包描述为已公证。实际上传副本的 `codesign --verify --deep --strict` 通过；`spctl --assess --type execute` 返回 `Unnotarized Developer ID`。

解锁后的界面复验能够读取窗口及文件选择器，但截图返回空白，随后出现 ScreenCaptureKit `-3812`。本次未完成的导入、海报、来源与播放器界面操作不计通过。隔离测试进程已关闭，未替换日常应用；日常媒体库的观看进度复核保留。

## 已完成

- 应用源码 GPL-3.0-or-later 公开仓库已建立。
- 原版副本的 45 个二进制完成 Developer ID 签名、安全时间戳和 Hardened Runtime 检查，包内依赖及 arm64 架构检查通过。
- 首次签名验证复现 LuaJIT 动态代码被系统终止。根据实际崩溃与上游应用配置，只加入 `allow-unsigned-executable-memory`，不关闭库验证、不添加调试权限。签名修复后才进行后续回归。
- 三次 45 秒核心回归，每次 31 项全部通过：导入、重扫、真实弹幕与缓存、暂停跳转、倍速、ASS 字幕、多音轨、关闭重开和数据库进度。它们不是三轮完整验收。
- 六项格式/异常短测通过：H.264 MP4、HEVC MOV、VP9 WebM、MPEG4 AVI、4K MP4，以及损坏 MKV 的可恢复错误。
- 从 DMG 复制到独立验证目录后，重新核对签名、运行权限、依赖和版本；没有覆盖日常应用或媒体库。该项在当前账户完成，不能计为干净账户验证。
- 30 份依赖源码归档校验通过，完整子模块、107 份许可文件及独立重建脚本已整理；详见 DEPENDENCY_SOURCES.md。
- 公开仓库已上传原版源码及发行准备材料，提交 `aeb5e74`；30 份源码归档完整性及非原版构建拒绝检查重跑通过，22 个原始代码/资源文件和 45 个可执行代码段重核一致。
- 曾通过 Xcode 已登录的账号上传 Apple 公证服务，提交编号 `419CF757-914F-4F34-AAD1-AC74DCB3CE86`；项目所有者随后决定跳过公证。该提交不作为最终发行门槛。

## 发布前仍需完成

- 原版 mpv 精确生产源码的对应确认。43 个依赖的代码段与已固定参考包相同；mpv 的字符串、C 函数及补丁一致，SDK/Swift 编译输出不同。这是来源推断，尚未复现其原始生产环境。
- 用户最初要求的三轮完整验收仍有未验证项目，包括独立账户、两小时前景压力、实际内容的 200ms 同步误差、休眠和外置盘恢复，详见 ACCEPTANCE_CHECKLIST.md。不把构建/短测成功计为这些项目通过。

安装包、依赖源码归档和校验值由 GitHub Release 提供。未公证与未完成的三轮验收必须在下载页继续明确标注；该发布不改变这些事实。
