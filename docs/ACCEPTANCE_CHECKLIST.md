# 三轮验收逐项清单

结论与版本以 [VERIFICATION.md](VERIFICATION.md) 为准。自动运行通过仅代表其列出的操作，不代表对应的整轮人工验收完成。JSON 保存每项步骤名称、时间、结果和细节；资源 CSV 与日志保留在同一轮目录。

第一、二轮自动结果对应构建 3；第三轮自动结果对应构建 2 的长测。构建 3 的完整第三轮尚未重跑。2026-11-22 已完成部分构建 3 原生界面检查，桌面实际片源引擎复测通过；界面工具后续窗口捕获错误，未计整轮通过。

当前补充：构建 8 已完成真实片源的正常媒体库导入、第一季官方候选确认、可读性设置保存、全屏／暂停／跳转和原生退出恢复，另重跑 31 项短流程及六类格式／异常检查。详见 [构建 8 报告](BUILD8.md)；下表历史轮次不能直接视为新构建整轮通过。

原版构建 9 的发行副本另有[打包核验记录](ORIGINAL_PACKAGE_CHECKS.json)和[当前发行状态](RELEASE_STATUS.md)：Developer ID 签名及三次核心短测通过，Apple 公证已上传并处于处理中。下表保留历史验收范围；其中旧的签名状态不代表当前发行副本，三轮完整验收仍未完成。
