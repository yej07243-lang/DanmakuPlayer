# 安装与恢复

DanmakuPlayer 0.1.0（构建 3）是本地验证包。三轮完整验收、Developer ID 签名、公证与依赖发布核对尚未全部完成。

## 安装

1. 打开 DMG，将 DanmakuPlayer 拖到 Applications；也可以放入个人 `~/Applications/` 目录。
2. 启动应用，导入自己的视频或文件夹。也可将文件拖入媒体库。文件会留在原处。
3. 双击海报开始播放；单击海报查看资料，右键可编辑或重新定位文件。

安装后的播放不需要 Homebrew。当前包仅包含 Apple Silicon 版本；最低系统声明为 macOS 14，实际运行验收机器为 macOS 27.2.1。

## 弹幕与播放

在影片详情中选择“关联 B 站弹幕”，搜索片名或粘贴 BV／番剧单集链接。选中候选和分 P，再确认关联。访问受限时可重试、使用已有缓存或导入本地 XML。

弹幕设置中可调整整体延后与分段校准点。整体延后为正时，弹幕在本地时间轴上更晚出现；校准点填写本地此刻对应的 B 站时间。同一集的不同剪辑可能需要多处校准。

空格暂停，左右方向键跳转五秒，F 全屏，D 切换弹幕。字幕、音轨、倍速和播放列表均有窗口内入口。播放时应用阻止自动息屏与空闲睡眠；暂停或关闭后释放。主动锁屏、合盖和系统休眠仍需分别验证。

## 升级与回退

1. 退出应用。
2. 备份整个 `~/Library/Application Support/DanmakuPlayer/` 文件夹，其中包括数据库、WAL、缓存、缩略图和日志。
3. 保留旧 `.app`，再替换为新版本。首版采用手动更新，菜单中的版本查看不会联网下载更新。
4. 如需回退，退出应用，恢复旧 `.app` 与此前备份的数据文件夹。不要在应用运行时只替换数据库主文件。

删除应用不会自动删除媒体库数据，也不会删除原始视频。文件移动或磁盘不可用时可保留记录，重新连接磁盘，或右键选择“重新定位文件”。

## 诊断与已知限制

菜单“媒体库 → 导出诊断日志…”可导出日志。日志不记录认证凭据。

已实测的短片源包括 H.264、HEVC、VP9、MPEG4、1080p 与 4K；不能据此推定所有同类文件均兼容。当前尚未完成 macOS 14、独立账户、真实休眠／外置盘断开及屏幕弹幕出现偏差的完整验收。
