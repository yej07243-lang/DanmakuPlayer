# 实测格式矩阵

机器为 Apple M5、16 GB、macOS 27.2.1。当前应用为 arm64；macOS 14、Intel 与 Windows 尚未运行验收。格式能力以具体编码、位深、轨道和素材为单位，不因扩展名相同就推定全部兼容。

| 容器／视频 | 分辨率／帧率 | 像素格式 | 音频／字幕素材 | 实测范围 |
| --- | --- | --- | --- | --- |
| MKV／H.264 | 1920×1080／30 fps | 8 bit yuv420p | 双 AAC、同名外置 SRT、另加载 ASS | 当前安装版核心播放、暂停、跳转、倍速、音轨与 ASS 选择；长测另见验收报告 |
| MP4／H.264 | 1920×1080／30 fps | 8 bit yuv420p | AAC | 当前安装版约 7 秒检查，片源 20 秒 |
| MOV／HEVC | 1920×1080／30 fps | 8 bit yuv420p | AAC | 当前安装版约 7 秒检查，片源 6 秒 |
| WebM／VP9 | 1920×1080／30 fps | 8 bit yuv420p | Opus | 当前安装版约 7 秒检查，片源约 6 秒 |
| AVI／MPEG4 | 1920×1080／30 fps | 8 bit yuv420p | MP3 | 当前安装版约 7 秒检查，片源约 6 秒 |
| MP4／H.264 4K | 3840×2160／30 fps | 8 bit yuv420p | 无音轨 | 当前安装版约 7 秒检查，片源 6 秒 |
| 用户《火线》S01E01 MP4／HEVC | 1920×1080／约 23.976 fps | 8 bit yuv420p | AAC；无单独字幕轨道 | 2026-11-22 桌面文件在构建 3 运行 20.345 秒，3/3 引擎检查通过；可见内容与整集未验证 |
| 损坏 MKV | 不适用 | 不适用 | 不适用 | 当前安装版显示解码错误，关闭错误后不会立即重现 |

各短时格式检查验证引擎打开、时间前进与错误状态；视频使用 VideoToolbox 的运行信息见对应 `round-21` 至 `round-25` 报告。它们不证明全片流畅、声道输出正确、字幕每个字形均正确或所有同类编码都能播放。

`artifacts/format-metadata.json` 另用安装包内同一 libmpv、每文件独立引擎读取元数据；该探测使用空输出和软件解码，仅用于确认上述素材参数，不代替播放器运行证据。

| 字幕与弹幕 | 结果 |
| --- | --- |
| 外置 SRT | 同名文件被引擎识别为 subrip；构建 3 已目视确认中文短句可读；延迟未测 |
| 外置 ASS | 自动加载与轨道选择通过；构建 3 已目视确认中文短句及样式显示；复杂样式未测 |
| 内嵌字幕、VTT、SSA、PGS | 入口或引擎可能支持；没有对应素材验收，不计通过 |
| 本地 XML 弹幕 | 解析、替换来源与每秒 100 条合成输入已验证；按密度限流 |
| B 站普通投稿分段弹幕 | 真实匿名下载、分 P 与缓存验证通过；不保证完整历史弹幕 |
| B 站公开番剧单集链接 | `ep830768` 的真实链接解析与弹幕取得通过；新构建人工绑定待验 |

10／12 bit、HDR／Dolby Vision、AV1、隔行视频、5.1／7.1、多设备音频输出、DTS／TrueHD、蓝光目录和网络串流均未列入本次通过范围。OpenGL 输出没有被认证为原生 HDR 输出。

2026-11-22 构建 8 已在 `round-83` 至 `round-88` 重跑上述五种格式和损坏 MKV 检查；真实《火线》在 `round-82` 运行 45 秒并完成原生画面／官方弹幕视觉检查。详见 [构建 8 报告](BUILD8.md)。

具体构建、哈希、步骤、失败历史和未完成项见 [验收报告](VERIFICATION.md) 与 [逐项清单](ACCEPTANCE_CHECKLIST.md)。
