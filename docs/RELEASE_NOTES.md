# DanmakuPlayer 0.1.0 构建 9

这是原版构建 9 的 Apple Silicon 直接下载版，适用于 macOS 14 或更新系统。安装后的播放不依赖 Homebrew。

## 下载与安装

- 下载 `DanmakuPlayer-0.1.0-build9-macos-arm64.dmg` 和 `SHA256SUMS`，先核对 SHA-256。
- 打开 DMG，将 DanmakuPlayer 拖入 Applications。
- 本包已使用 Developer ID 签名，但**没有 Apple 公证**。首次启动若被 macOS 拦截，请打开“系统设置 → 隐私与安全性”，选择“仍要打开”并再次确认。
- 不要通过 `xattr` 或第三方脚本删除隔离标记。

## 主要功能

- 原生媒体库、文件及文件夹递归导入、搜索、电影／剧集分组、继续观看与失效文件重新定位。
- 内置 libmpv 播放内核，支持常见本地视频、多音轨、SRT／ASS 字幕、倍速、全屏和播放进度恢复。
- B 站普通投稿搜索、BV／短链接及可公开解析的番剧单集链接导入，支持候选确认、分 P、缓存和本地 XML。
- 弹幕字号、透明度、类型、速度、显示区域、密度、屏蔽词、整体延迟及分段校准。

## 已验证范围

- 签名候选三次 45 秒核心回归各 31/31 项通过；最终 DMG 复制安装后又跑第四次 45 秒回归，31/31 项通过且播放持续推进。覆盖真实 B 站请求、缓存、播放、音轨、字幕、跳转、退出恢复和数据库重开。
- H.264、HEVC、VP9、MPEG4、1080p、4K 及损坏 MKV 的短时检查通过。
- DMG、安装后 45 个二进制签名、依赖和 arm64 架构检查通过，应用及依赖可执行代码段与原始构建一致。

这些结果不是三轮完整人工验收。尚无充分证据覆盖 macOS 14 实机、独立账户、真实断网、外置盘断开、整机休眠、两小时前景高密度弹幕、同版片源屏幕偏差不超过 200ms。

## 数据与回退

数据保存在 `~/Library/Application Support/DanmakuPlayer/`。升级或回退前退出应用并备份整个目录。删除应用不会删除媒体库数据或原视频。
