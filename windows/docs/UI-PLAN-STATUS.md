## 阶段验收（W0–W3）

| 阶段 | 状态 | 证据 / 缺口 |
| --- | --- | --- |
| W0 播放原型 | ✅ | libmpv 出画、有声音（WASAPI 48 kHz 链路）、时间推进；HwndHost 合成弹幕与控件；全屏/退出正常 |
| W1 媒体库 | ✅ | SQLite、扫描去重、季集分组、继续观看、重新定位、无图占位；重扫/重开保留同一记录 |
| W2 播放与弹幕 | ✅ | 字幕延迟、音轨、倍速、剧集列表、B 站候选/来源确认/缓存/XML、正偏移与分段点、换源重置校准 |
| W3 打包与回归 | 🟡 | 已出自包含 x64 发布包并解压验证；剩余：干净环境安装/覆盖升级、100%/125%/150% 缩放、双屏、讲述人验收 |

- 100%、125%、150% 缩放下的布局与视频区域；双屏拖动、贴靠、最大化、全屏、Esc 恢复。
- 讲述人（Narrator）走查：标题、进度、轨道选择、错误状态。
- 干净 Windows 11 环境安装、覆盖升级后媒体库/来源/校准/设置恢复。
- 长时间播放（2 小时以上）稳定性。
